# Wct.by — Интернет-магазин

## Обзор
Веб-приложение интернет-магазина на Laravel 12 с админ-панелью MoonShine, аутентификацией через Fortify/Socialite, медиа-библиотекой Spatie и Bootstrap-темой Cartzilla.

## Основные возможности
- Каталог товаров с категориями, фильтрацией и полнотекстовым поиском
- Корзина и список желаний (гостевые и авторизованные, слияние при входе)
- Оформление заказа с выбором способов доставки и оплаты
- Аутентификация: email/пароль, соцсети (Google, Yandex), 2FA
- Личный кабинет: профиль, заказы, адреса
- Админ-панель MoonShine: управление товарами, категориями, заказами, пользователями
- Связки товаров (bundles), SKU с атрибутами
- Email-уведомления о заказах

## Технический стек
- **Язык:** PHP 8.2+
- **Фреймворк:** Laravel 12
- **База данных:** MySQL 8.4
- **ORM:** Eloquent (встроенный в Laravel)
- **Фронтенд:** Blade + Tailwind CSS 4 + Vite, тема Cartzilla (Bootstrap)
- **Админ-панель:** MoonShine 4 (русская локализация)
- **Аутентификация:** Laravel Fortify + Socialite (Google, Yandex)
- **Медиа:** Spatie Media Library 11
- **Права доступа:** Spatie Laravel Permission 6
- **Тестирование:** PHPUnit 11, Laravel-тесты (RefreshDatabase)
- **Логирование:** Стандартный стек Laravel (single-файл)
- **CI/CD:** Не настроено

## Архитектура
Подробные архитектурные рекомендации и правила зависимостей описаны в `.ai-factory/ARCHITECTURE.md`.
Паттерн: **Structured Modules (Technical Layers)**.

## Примечания по архитектуре
- Контроллеры тонкие — валидируют вход, вызывают сервисы, возвращают представления
- Сервисы (`app/Services/`) содержат бизнес-логику
- Модели (`app/Models/`) содержат связи, аксессоры и scopes
- Паттерн гостевой корзины: сессионные токены, слияние при входе
- Админ-панель MoonShine с отдельным guard
- Все роуты в `web.php`, именованные с dot-префиксами групп
- Формат номера заказа: `ORD-YYYYMMDD-XXXXXX`
- Обработка ошибок: исключения через `abort()`, `findOrFail()`, try/catch с DomainException

## Нефункциональные требования
- **Логирование:** Настраивается через LOG_LEVEL (по умолчанию debug)
- **Обработка ошибок:** Исключения с понятными сообщениями, flash-сообщения через сессию
- **Безопасность:** CSRF, Fortify 2FA, rate limiting на корзину/оформление, email-верификация
