# Дорожная карта проекта

> Интернет-магазин Wct.by: от функционального MVP к полноценной коммерческой платформе.

## Вехи

- [x] **Каталог товаров** — категории, продукты, SKU с атрибутами, полнотекстовый поиск, фильтрация по флагам и цене, хлебные крошки
- [x] **Корзина и Wishlist** — гостевая и авторизованная корзина, слияние при входе, поли-элементы (Product/SKU), очистка истёкших
- [x] **Оформление заказа** — модели Order/OrderItem, выбор доставки и оплаты, генерация номера заказа с повторами при коллизиях
- [x] **Профиль и адреса** — управление профилем, аватаром, паролем, соцсвязями, адресами доставки/оплаты
- [x] **Аутентификация** — Fortify (email/пароль, 2FA, верификация) + Socialite (Google, VK, Yandex, Telegram)
- [x] **Админ-панель MoonShine** — 19 ресурсов (все модели), RBAC через Spatie Permission, WYSIWYG, файловый менеджер
- [x] **Email-уведомления** — подтверждение заказа клиенту, новое письмо администратору, через ShouldQueue
- [x] **CMS-страницы** — публичный фронтенд для модели Page (модель и админ-CRUD уже есть, нет маршрутов и Blade-шаблонов)
- [ ] **Платёжный шлюз** — интеграция с YooKassa / Stripe / WebPay, обработка callback, статусы платежей
- [ ] **Интеграция доставки** — API СДЭК / Почты России, расчёт стоимости, трекинг-номер, статусы доставки
- [x] **Статусная модель заказов** — workflow (new → processing → shipped → delivered → cancelled), история изменений, уведомления о смене статуса
- [x] **События и слушатели** — OrderCreated, OrderStatusChanged, LowStock — decoupling через события Laravel, фоновые слушатели
- [ ] **Промокоды и скидки** — модель Coupon, валидация в корзине, расчёт скидки при оформлении заказа
- [x] **Отзывы и рейтинги** — модель Review, звёздный рейтинг, модерация, отображение на странице товара
- [x] **Фильтрация по атрибутам** — EAV-модель готова, нужен фронтенд-фильтр (цвет, размер и т.д.) в каталоге
- [x] **Бандлы на фронтенде** — модели Bundle готовы, нужен публичный показ наборов товаров и покупка через корзину
- [x] **Импорт/экспорт товаров** — CSV/XML импорт и экспорт каталога через админ-панель
- [ ] **CI/CD и инфраструктура** — GitHub Actions (тесты + линтинг + деплой), Docker (dev и production), Sail
- [ ] **Тестовое покрытие** — расширить с 12 тестов до покрытия каталога, оформления заказа, админки (80%+ критической логики)
- [ ] **REST API** — Sanctum-аутентификация, маршруты `/api/`, документация конечных точек
- [ ] **Аналитика и SEO** — GA4 и Yandex.Metrika, XML sitemap, микроразметка, Open Graph
- [ ] **Товарные фиды и сравнение** — Яндекс.Маркет, Google Merchant Center, функционал сравнения товаров
- [ ] **Парсинг товаров** — импорт товаров с внешних сайтов по URL, DOM-парсинг, создание черновиков
