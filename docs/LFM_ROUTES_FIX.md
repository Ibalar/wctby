# Исправление задачи 4.2.7: Дублирование маршрутов laravel-filemanager

## Статус: ✅ Исправлено

## Проблема

Маршруты `laravel-filemanager` были зарегистрированы в двух местах:
1. `routes/web.php` (строки 16-18)
2. `routes/moonshine.php` (строки 8-10)

Это приводило к дублированию маршрутов и потенциальным конфликтам.

## Решение

Удалена регистрация маршрутов из `routes/web.php`, оставлена только в `routes/moonshine.php`.

### Изменения

**Файл:** `routes/web.php`

**Удалено:**
```php
use UniSharp\LaravelFilemanager\Lfm;

Route::prefix('laravel-filemanager')->group(function () {
    Lfm::routes();
});
```

**Оставлено:** `routes/moonshine.php` (без изменений)
```php
Route::prefix('laravel-filemanager')->group(function () {
    Lfm::routes();
});
```

## Обоснование

`laravel-filemanager` используется в административной панели MoonShine (интеграция с TinyMCE), поэтому логичнее регистрировать его маршруты в `routes/moonshine.php`, а не в публичных маршрутах `web.php`.

## Проверка

### 1. Поиск дублирования

```bash
grep -r "Lfm::routes" --include="*.php" routes/
```

**Результат:**
```
routes/moonshine.php:9:    Lfm::routes();
```

✅ Маршруты зарегистрированы только в одном месте

### 2. Проверка синтаксиса

```bash
php -l routes/web.php
php -l routes/moonshine.php
```

**Результат:** Оба файла прошли проверку ✅

### 3. Проверка доступности маршрутов

Маршруты `laravel-filemanager` остаются доступными через `routes/moonshine.php`, который загружается MoonShine package.
