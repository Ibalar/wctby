# CMS-страницы

## Обзор

Система управления контентом (CMS) для статических страниц сайта. Позволяет создавать и редактировать страницы через админ-панель MoonShine и отображать их на публичной части сайта.

## Использование

Страницы доступны по адресу `/page/{slug}`. Slug задаётся при создании страницы в админ-панели.

Примеры:
- `/page/about` — страница «О магазине»
- `/page/delivery` — страница «Доставка и оплата»
- `/page/contacts` — страница «Контакты»

## Компоненты

| Компонент | Путь | Назначение |
|-----------|------|------------|
| PageController | `app/Http/Controllers/PageController.php` | Публичный показ страницы по slug |
| PageResource | `app/MoonShine/Resources/Page/` | CRUD в админ-панели MoonShine |
| PageFactory | `database/factories/PageFactory.php` | Фабрика для тестов и сидов |
| PageTest | `tests/Feature/PageTest.php` | Feature-тесты (3 кейса) |
| Шаблон | `resources/views/pages/show.blade.php` | Blade-представление |

## Модель Page

Поля:
- `slug` — уникальный URL-идентификатор
- `title` — заголовок страницы (также используется в `<title>`)
- `content` — HTML-содержимое страницы
- `is_active` — флаг активности (неактивные возвращают 404)

## Админ-панель

В MoonShine доступен раздел «Страницы» со стандартным CRUD:
- Список с фильтрацией (все/активные/неактивные)
- Создание/редактирование (поля: заголовок, slug, содержимое, активность)
- Валидация: slug уникальный, title обязательный

## Хлебные крошки

Для страниц отображаются упрощённые крошки: Главная → Название страницы.

## Тестирование

```bash
php artisan test --filter PageTest
```

3 тестовых кейса:
1. Активная страница отображается (200, title и content в ответе)
2. Неактивная страница возвращает 404
3. Несуществующий slug возвращает 404
