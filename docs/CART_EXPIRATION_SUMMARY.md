# Реализация задачи 4.2.4: Обработка истёкших гостевых корзин

## Статус: ✅ Завершено

## Проблема

Гостевые корзины накапливались в БД без механизма очистки, что приводило к:
- Росту размера БД
- Замедлению запросов
- Хранению устаревших данных

## Решение

Реализована комплексная система обработки истёкших корзин:

### 1. Автоматическая очистка при обращении ✅

При каждом обращении к корзине через `CartService::getOrCreateCart()`:
- Проверяется поле `expires_at`
- Если корзина истекла — удаляется с items
- Создаётся новая корзина с новым сроком действия

### 2. Защита от слияния истёкших корзин ✅

При логине пользователя:
- Проверяется срок действия гостевой корзины
- Истёкшие корзины не сливаются с корзиной пользователя
- Истёкшая корзина удаляется

### 3. Artisan команда для массовой очистки ✅

```bash
php artisan cart:cleanup
```

**Особенности:**
- Удаляет только истёкшие гостевые корзины (по `expires_at`)
- Использует транзакции для атомарности
- Массовое удаление через `whereIn()` для производительности
- Выводит статистику удалённых корзин

### 4. Автоматический запуск через Scheduler ✅

Команда запускается ежедневно в 3:00:

```php
$schedule->command('cart:cleanup')->dailyAt('03:00');
```

### 5. Полное тестовое покрытие ✅

**CartCleanupCommandTest** (4 теста):
- ✅ Удаление истёкших гостевых корзин
- ✅ Сохранение активных гостевых корзин
- ✅ Игнорирование корзин пользователей
- ✅ Массовое удаление нескольких корзин

**CartExpirationTest** (8 тестов):
- ✅ Автоматическая очистка при обращении
- ✅ Сохранение активной корзины
- ✅ Отказ от слияния истёкшей корзины
- ✅ Слияние активной корзины при логине
- ✅ Проверка метода `isExpired()` (3 теста)
- ✅ Создание новой корзины с правильным сроком

## Преимущества реализации

1. **Проактивная очистка** — корзины удаляются при обращении, не дожидаясь cron
2. **Двойная защита** — автоматическая + плановая очистка
3. **Производительность** — массовые операции в транзакции
4. **Безопасность** — истёкшие данные не попадают в корзину пользователя
5. **Тестируемость** — полное покрытие тестами
6. **Масштабируемость** — работает эффективно с большим количеством корзин
