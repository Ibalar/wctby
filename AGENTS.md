# AGENTS.md

> Этот файл генерируется и поддерживается AI Factory. Не редактируйте вручную.

## Обзор проекта
Интернет-магазин Wct.by на Laravel 12 с админ-панелью MoonShine, аутентификацией Fortify/Socialite и Bootstrap-темой Cartzilla.

## Технический стек
- **Язык:** PHP 8.2+
- **Фреймворк:** Laravel 12
- **База данных:** MySQL 8.4
- **ORM:** Eloquent (встроенный)
- **Фронтенд:** Blade + Tailwind CSS 4 + Vite, тема Cartzilla
- **Тестирование:** PHPUnit 11

## Ключевые точки входа
| Файл | Назначение |
|------|------------|
| `public/index.php` | Фронт-контроллер, точка входа всех HTTP-запросов |
| `artisan` | Консольный интерфейс Laravel (миграции, команды, tinker) |
| `routes/web.php` | Определение всех веб-маршрутов |
| `config/app.php` | Основная конфигурация приложения |
| `app/Http/Controllers/Controller.php` | Базовый абстрактный контроллер |
| `vite.config.js` | Сборка фронтенд-ресурсов |

## Правила для агентов
- При выполнении shell-команд с `&&` в PowerShell — замена на последовательный вызов: сначала первая команда, потом `if ($?) { вторая }`.
  - Неправильно (скомбинированная команда): `git checkout main && git pull`
  - Правильно (разделённая): сначала `git checkout main`, затем `git pull origin main`
