# Wct.by — Интернет-магазин

> Современный интернет-магазин на Laravel 12 с админ-панелью MoonShine.

Wct.by — веб-приложение интернет-магазина с каталогом товаров, корзиной, оформлением заказов и личным кабинетом. Админ-панель MoonShine обеспечивает управление товарами, категориями, заказами и пользователями.

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone git@github.com:Ibalar/wctby.git
cd wctby

# 2. Установить зависимости
composer install
npm install

# 3. Настроить окружение
cp .env.example .env
php artisan key:generate

# 4. Настроить БД в .env и запустить миграции
php artisan migrate --seed

# 5. Собрать фронтенд и запустить
npm run build
php artisan serve
```

## Основные возможности

- **Каталог товаров** — категории, фильтрация, полнотекстовый поиск
- **Корзина и Wishlist** — поддержка гостей, слияние при авторизации
- **Оформление заказа** — выбор доставки и оплаты, уведомления на email
- **Личный кабинет** — профиль, история заказов, адреса
- **Аутентификация** — email/пароль, соцсети (Google, Yandex), 2FA через Fortify
- **Админ-панель** — MoonShine: управление товарами, SKU, заказами, пользователями, связками

---

## Запуск через Docker

```bash
cp .env.example .env
docker compose up -d
# Открыть http://localhost:8080
```
